Walkie Talkie.

This code shows how walkie talkie works, when speak button is pressed.

There are subsystems hidden to a Client(Main):  ActivateTransmitter, CloseCircuit, ConvertVoiceToRadioSignal, TransmitSignal. 
In simple words, CloseCircuit means button connected wires, ActivateTransmitter is swithing to speak mode, ConvertVoiceToRadioSignal is converter, TransmitSignal is antenna.
